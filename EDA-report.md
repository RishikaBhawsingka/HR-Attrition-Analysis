# IBM HR Analytics — Exploratory Data Analysis Report

## 1. Project Overview

This project analyzes employee workforce and attrition data using Python and Power BI.

The objective is to transform raw HR data into an executive-level interactive dashboard that helps HR stakeholders understand:

- Employee workforce composition
- Employee attrition patterns
- Departments and roles with higher attrition
- Factors associated with employee turnover
- Workforce satisfaction and work-life indicators
- Areas requiring potential retention strategies
